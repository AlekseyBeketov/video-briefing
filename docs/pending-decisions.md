# Pending decisions

Есть решения, которые остаются за владельцем проекта:

- **Лицензия и условия использования.** В репозитории нет `LICENSE`; документация не заявляет выбранную лицензию. Перед выбором и публикацией лицензии нужно определить желаемые права на использование, изменение и распространение.
- **Официальная матрица платформ.** CI проверяет Python 3.11–3.14 на Ubuntu. Поддержка других ОС не подтверждена тем же автоматическим контуром; решить, какие платформы обещать пользователям и добавить ли для них CI.
- **Публикация установочных артефактов.** Документация описывает установку из checkout, потому что в tracked checkout нет wheel. Создание релиза или публикация пакета остаются отдельным решением.

Не принимать автоматически: новая платная API/compute услуга; получение browser cookies; residential proxies; крупные необязательные model downloads; публикация raw transcripts; изменение глобальных конфигов или других профилей. Если потребуется — записать точный вопрос, варианты и последствия, затем ждать пользователя без timeout default.
