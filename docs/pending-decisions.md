# Pending decisions

Есть решения, которые остаются за владельцем проекта:

- **Официальная матрица платформ.** CI проверяет Python 3.11–3.14 на Ubuntu. Поддержка других ОС не подтверждена тем же автоматическим контуром; решить, какие платформы обещать пользователям и добавить ли для них CI.
- **Публикация установочных артефактов.** Документация описывает установку из checkout, потому что в tracked checkout нет wheel. Создание релиза или публикация пакета остаются отдельным решением.

Не принимать автоматически: новая платная API/compute услуга; получение browser cookies; residential proxies; выбор обеих крупных ASR-моделей без явного запроса; публикация raw transcripts; изменение глобальных конфигов или других профилей. `setup-asr` скачивает только выбранные пользователем языки и показывает размер, лицензию и целевой путь до подтверждения. Если требуется другое крупное необязательное скачивание — записать точный вопрос, варианты и последствия, затем дождаться решения.
